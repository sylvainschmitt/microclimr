# Package index

## Data

Micro- and macro-climate data

- [`era`](https://sylvainschmitt.github.io/microclimr/reference/era.md)
  : ERA5-Land macroclimatic data for the Mormal forest
- [`hobo`](https://sylvainschmitt.github.io/microclimr/reference/hobo.md)
  : HOBO micrloclimatic data from the Mormal forest
